# Yashoday HealthCare Agency Website

A responsive static website made with HTML, CSS and vanilla JavaScript, using the logo and healthcare images supplied for this project.

## Included
- `index.html` — website structure and page content
- `css/style.css` — responsive styling
- `js/script.js` — mobile navigation, current year and enquiry form behaviour
- `assets/` — supplied Yashoday logo and healthcare photos

## How to view the website
1. Extract the ZIP file.
2. Open the extracted `yashoday_healthcare_website` folder.
3. Double-click `index.html` to open it in a browser.

For local development, you can also open the folder in VS Code and use the Live Server extension.

## How the enquiry form works
The form validates the required fields and opens WhatsApp with the visitor's enquiry pre-filled for the visitor to review and send. It does not store submissions or send messages automatically. To collect enquiries directly on a server or by email, connect the form to a backend or a form-processing service.

## How to publish
Upload the contents of this folder (including `index.html`, `css`, `js` and `assets`) to your hosting account's public web directory, commonly named `public_html`. Keep the folder structure unchanged.

## Editing
- Change page text and services in `index.html`.
- Change colours, spacing and layout in `css/style.css` (the main colour variables are at the top).
- Change the WhatsApp number in `js/script.js` and in the WhatsApp links in `index.html` if the number changes.
- Replace images inside `assets/` while keeping the filenames the same, or update the matching image paths in `index.html`.
